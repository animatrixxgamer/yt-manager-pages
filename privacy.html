Privacy Policy

Last updated: September 13, 2026

1 Overview

Animatrixx YT Manager ("the Application") is a personal automation tool built for managing YouTube channels. This Privacy Policy explains how the Application handles data and interacts with Google APIs.

This Application is intended for personal use only and is not distributed publicly.

2 Information We Collect

The Application does not collect, store, or share any personal user data. It does not use cookies, analytics, or tracking mechanisms of any kind.

The only data the Application handles are:

  • OAuth 2.0 credentials (Client ID, Client Secret, Refresh Token) used to authenticate with the YouTube Data API v3.
  • Video files and metadata provided by the user for upload.

3 How We Use Google User Data

Animatrixx YT Manager uses YouTube API Services to perform the following actions on the authorized channel:

  • Upload videos to the user's own YouTube channel.
  • Set video metadata (title, description, tags, hashtags, privacy status).
  • Manage playlists and channel content.
  • Read channel information for automation purposes.

By using this Application, you agree to be bound by the YouTube Terms of Service.

You can review Google's privacy practices at the Google Privacy Policy.

4 Data Sharing

No user data is shared with third parties. All data stays between the user, Google's APIs, and the locally-hosted bot application.

5 Data Retention & Deletion

Since no user data is stored by this Application, there is no data to retain or delete. OAuth tokens are stored locally on the user's own device/server.

You can revoke the Application's access to your Google account at any time by visiting your Google Account Permissions page.

6 Security

The Application uses Google's official OAuth 2.0 authentication flow. Refresh tokens are stored securely in environment variables and never exposed publicly.

7 Changes to This Policy

This Privacy Policy may be updated occasionally. Any changes will be reflected on this page with an updated revision date.
