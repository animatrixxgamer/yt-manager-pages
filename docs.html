Quick Start

Get the bot running locally in 3 commands:

# 1. Install dependencies
pip install -r requirements.txt

# 2. Configure
cp .env.example .env
# Edit .env with your tokens

# 3. Run!
python bot.py

Environment Variables

Required

BOT_TOKEN=your_telegram_bot_token
OWNER_ID=your_telegram_user_id
YOUTUBE_CLIENT_ID=your_google_client_id
YOUTUBE_CLIENT_SECRET=your_google_client_secret
YOUTUBE_REDIRECT_URI=https://your-domain.com/oauth/youtube/callback

Optional

PREFER_ENV_FILE=1
SOCIAL_COOKIES_FILE=storage/cookies.txt
TIKTOK_POLL_SECONDS=900
SCHEDULER_TICK_SECONDS=30
PUBLIC_BASE_URL=https://your-app.fly.dev
STORAGE_DIR=/data
💡 Tip: On Railway, set STORAGE_DIR=/data and create a volume mounted at /data so your connected channels survive redeploys.

YouTube OAuth Setup

  1. Go to Google Cloud Console
  2. Create a project → enable YouTube Data API v3
  3. Credentials → OAuth Client ID → type Web application
  4. Add your redirect URI: https://your-domain.com/oauth/youtube/callback
  5. Copy the Client ID and Client Secret into your .env

Run /diag in the bot to see the exact redirect URI to use.

Deploy on Railway

  1. Push your code to GitHub
  2. Go to Railway.app
  3. New Project → Deploy from GitHub repo
  4. Add environment variables in the Variables tab
  5. Settings → Volumes → New Volume → mount at /data
  6. Settings → Networking → Generate Domain
  7. Copy the URL and set YOUTUBE_REDIRECT_URI to https://your-domain.up.railway.app/oauth/youtube/callback
  8. Add the same URI to Google Cloud Console

Uploads

Send a video to the bot or use /upload. You can:

  • Upload as a Short (auto-tagged #shorts)
  • Upload as a regular video
  • Import from a link (TikTok, Instagram, etc.)
  • Bulk upload many links at once

TikTok Auto-Post

Use /tiktok @username or send a TikTok profile link. The bot will:

  • Poll for new videos on the source
  • Download them
  • Publish to your chosen channel with the settings you configure

Social Downloads

Paste any link, or use /dl <link>. Supported platforms:

YouTube · TikTok · Instagram · X/Twitter · Facebook · Reddit · Vimeo · Twitch · Pinterest · Dailymotion · Snapchat · Likee · Kwai · Rumble · Odysee

Troubleshooting

Bot doesn't respond to commands

Run /diag to check if the bot is alive. If nothing happens, the token may be wrong.

"Google hasn't verified this app"

This is normal for personal bots. Click Advanced → Go to [App] (unsafe).

OAuth redirect mismatch

Copy the redirect URI from /diag and add it to Google Cloud Console → Credentials → Authorized redirect URIs.

Uploads fail with quota error

YouTube gives 10,000 units/day. Each upload costs ~1,600 units, so about 6 uploads/day max.
