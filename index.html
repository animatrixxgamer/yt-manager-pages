Animatrixx YT Manager

A personal automation tool for managing YouTube channels — uploads, metadata, and content scheduling, all in one place.

Personal Tool

🎯 What This App Does

Animatrixx YT Manager is a custom-built personal automation tool that streamlines YouTube channel management. It connects to the YouTube Data API v3 to handle video uploads, metadata configuration, and content organization through a secure Telegram bot interface.

This application is intended for personal use only. It does not collect, store, or share any user data with third parties.

⚡ Key Features

📤 Automated Uploads

Upload videos directly to authorized YouTube channels via Telegram.

🏷️ Metadata Management

Set titles, descriptions, tags, and hashtags automatically.

🔄 Multi-Channel Support

Manage multiple YouTube accounts and brand channels from one bot.

🔒 Secure OAuth 2.0

Uses Google's official OAuth 2.0 flow with offline refresh tokens.
