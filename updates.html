Fix September 15, 2026

🔧 OAuth "Link expired" bug fixed

If you were seeing "Link expired" or invalid_grant errors when connecting YouTube, this is fixed in v3.2. The causes were:

  • Whitespace in environment variables poisoning the request
  • Authorization codes being URL-decoded twice
  • State tokens not being burned before exchange

Update your deployment to pick up the fix. See the changelog for details.
