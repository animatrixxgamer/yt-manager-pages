Changelog

New features, fixes, and improvements.

v4.0 — Epic Edition Latest September 19, 2026
  • 🆕 Upload Hub — Pick Shorts, Video, Link, or Bulk before uploading
  • 🆕 Channel Dashboard — Full control panel for each channel
  • 🆕 Analytics Dashboard — Views, likes, subscribers at a glance
  • 🆕 Manage Videos — Browse, filter, edit, and delete uploads
  • 🆕 Shorts Auto-Tag — Shorts automatically get #shorts
  • 🆕 Colored Buttons — Blue / Green / Red for clarity
  • 🆕 TikTok Auto-Post — Full polling system with per-source controls
  • 🆕 Bulk Downloads — Whole TikTok accounts, up to 50 links at once
  • 🆕 Multi-Channel — Connect and switch between multiple channels
  • 🆕 Fernet Encryption — OAuth tokens encrypted at rest
  • 🆕 Admin Panel — Stats, users, ban/unban, premium, broadcast
  • 🆕 File Hosting — Host .py, .js, .zip with auto-install
  • 158 automated tests — Every button verified to have a handler
v3.2 — OAuth Multi-User Fix September 15, 2026
  • Fixed invalid_grant from whitespace in env variables (.strip())
  • Added URL-decode of authorization codes — fixes %2F double-encoding
  • State tokens now burned before exchange — prevents replay "Link expired" errors
  • Access tokens cached in memory — faster uploads
  • invalid_grant now marks channels as revoked for cleaner UX
  • Disconnect button added — revokes tokens at Google and deletes DB row
  • Paste-code fallback now uses shared helpers (single decode path)
v3.0 — Real Uploads September 10, 2026
  • Real resumable uploads with live progress bar
  • Retry with exponential backoff
  • Native YouTube scheduling via publishAt
  • Per-video stats: views, likes, comments
  • Thumbnail upload from photos
  • Channel switcher — active channel remembered per user
v2.0 — Social Imports September 5, 2026
  • yt-dlp integration — download from 15+ platforms
  • Bulk downloads — paste 50 links at once
  • Signed download links for files over 50MB
  • My Downloads — re-download, zip, or queue saved files
v1.0 — Initial Release September 1, 2026
  • Basic YouTube upload from Telegram
  • OAuth 2.0 connection flow
  • SQLite storage
  • Queue system
